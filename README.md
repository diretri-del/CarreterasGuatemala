# 🛣️ Proyecto Base de Datos: Carreteras de Guatemala
**Universidad InterNaciones (UNIPRO)**  
**Asignatura:** Base de Datos  

## 📌 Descripción
Proyecto que implementa la base de datos relacional y una interfaz Java en NetBeans para administrar las carreteras, sus tramos y las comunas asociadas.

## 📁 Archivos Incluidos
- `script_bd.sql`: Script de creación de la base de datos y carga de datos iniciales.
- `ConexionBD.java`: Clase encargada de la conexión JDBC a la base de datos SQL.
- `Main.java`: Aplicación ejecutable que consulta e imprime los datos del sistema.

## 🚀 Instrucciones de Uso
1. Cargar el script `script_bd.sql` en el motor de base de datos SQL.
2. Configurar usuario/contraseña en `ConexionBD.java`.
3. Ejecutar `Main.java` desde NetBeans.
